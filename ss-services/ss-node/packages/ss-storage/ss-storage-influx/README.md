# @ss-node/ss-storage-influx

Smart SCADA InfluxDB Storage Plugin — 历史数据存储插件。

## Exports

- `DataModule` — NestJS 模块
- `DataService` — 历史数据查询（时间范围/最新值）
- `HistoricalData` Entity — 多种数据类型存储(numeric/string/boolean)

## Usage

```typescript
import { DataModule } from '@ss-node/ss-storage-influx';
```
