# @ss-node/ss-collector-modbus

Smart SCADA Modbus Collector — Modbus TCP/RTU 协议采集插件。

## Exports

- `ModbusCollectorModule` — NestJS 模块
- `ModbusService` — 实现 `IProtocolAdapter` 接口

## Usage

```typescript
import { ModbusCollectorModule } from '@ss-node/ss-collector-modbus';
```
