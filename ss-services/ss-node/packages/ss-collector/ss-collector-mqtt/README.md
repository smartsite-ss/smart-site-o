# @ss-node/ss-collector-mqtt

Smart SCADA MQTT Collector — MQTT 协议采集插件。

## Exports

- `MqttCollectorModule` — NestJS 模块
- `MqttService` — 实现 `IProtocolAdapter` 接口

## Usage

```typescript
import { MqttCollectorModule } from '@ss-node/ss-collector-mqtt';
```
