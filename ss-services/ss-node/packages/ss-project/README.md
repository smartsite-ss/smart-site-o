# @ss-node/ss-project

Smart SCADA Project Management Library — 项目管理与页面管理。

## Exports

- `ProjectModule` — NestJS 模块
- `ProjectService` — 项目 CRUD + 导入/导出
- `Project` Entity, `Page` Entity

## Usage

```typescript
import { ProjectModule } from '@ss-node/ss-project';
```
