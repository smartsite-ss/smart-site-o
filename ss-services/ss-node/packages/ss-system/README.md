# @ss-node/ss-system

Smart SCADA System Management Library — 系统健康检查、系统信息、配置管理。

## Exports

- `SystemModule` — NestJS 模块
- 健康检查: `GET /system/health`
- 系统信息: `GET /system/info`

## Usage

```typescript
import { SystemModule } from '@ss-node/ss-system';
```
