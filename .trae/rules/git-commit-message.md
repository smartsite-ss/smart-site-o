## Smart Site V7 提交信息规范

### 格式

```
<类型>: <模块>-<简要描述> —模型名
```

> **模型名**：记录本次提交所用的 AI 模型，如 `DeepSeek-V4-Pro`、`GLM-5.2`、`Claude-4.5-Opus` 等。人工编写则省略。

### 类型前缀

| 类型     | 说明                       |
| -------- | -------------------------- |
| feat     | 新增功能                   |
| fix      | 修复 bug                   |
| refactor | 重构代码（不改变功能）     |
| docs     | 文档更新                   |
| style    | 代码格式调整（不影响逻辑） |
| test     | 测试相关                   |
| chore    | 构建/工具链相关            |
| perf     | 性能优化                   |

### 模块前缀

按两大子系统划分：

#### ss-scada（组态编辑器 + 运行器）

| 模块     | 范围                                                             | 示例                                               |
| -------- | ---------------------------------------------------------------- | -------------------------------------------------- |
| 编辑器   | 图元编辑、画布、页面、属性面板、快捷键、撤销重做、图层、对齐吸附 | feat: 编辑器-图元支持旋转角度输入 —DeepSeek-V4-Pro |
| 运行态   | 预览模式、数据绑定、事件交互、定时任务、脚本执行、告警检测       | fix: 运行态-数据绑定延迟 —GLM-5.2                  |
| 插件图元 | 插件开发、SDK、渲染后端、插件发布                                | feat: 插件图元-新增 SVG 渲染后端 —Claude-4.5-Opus  |
| 主题样式 | 主题系统、CSS 变量、暗色模式                                     | feat: 主题样式-新增绿色科技主题 —DeepSeek-V4-Pro   |

#### ss-data（数据中台）

| 模块     | 范围                                              | 示例                                             |
| -------- | ------------------------------------------------- | ------------------------------------------------ |

| 采集管理 | 采集器、协议适配(Modbus/OPC UA/MQTT/S7)、采集调度 | fix: 采集管理-虚拟设备状态统计不正确 —GLM-5.2    |
| 数据标签 | 标签定义、标签绑定、变量管理                      | refactor: 数据标签-优化查询性能 —DeepSeek-V4-Pro |

#### 其他

| 模块     | 范围                         | 示例                                             |
| -------- | ---------------------------- | ------------------------------------------------ |

### 示例

```
feat: 设备管理-分组支持拖拽排序 —DeepSeek-V4-Pro
fix: 设备管理-分组创建后未刷新列表 —GLM-5.2
refactor: 系统-菜单改为集中配置 —Claude-4.5-Opus
docs: 设计文档-菜单配置方案 —DeepSeek-V4-Pro
fix: 采集管理-虚拟设备状态统计不正确 —GLM-5.2
feat: 编辑器-图元支持旋转角度输入 —DeepSeek-V4-Pro
```

### 原则

- **尽量说明原因**，而不是单纯描述做了什么
- 保持简洁，不超过 50 个字符
- 使用中文描述
